# 🌍 Planetary Eco-Passport

> *Your digital identity for tracking, gamifying, and improving real-world sustainability.*

Welcome to the **Eco-Passport** repository! Built for the Hack Club Embassy program, this project blends digital government identity aesthetics with real-world carbon tracking. Instead of a boring carbon calculator spreadsheet, Eco-Passport turns your daily habits into an official, high-tech biometric passport complete with laser-etched visa stamps and real-time score readouts.

---

## ✨ What Makes It Special?

* **Futuristic Biometric Aesthetic:** Styled like the most advanced modern electronic passports (featuring dark polycarbonate card gradients, subtle scan-line visual effects, and neon biometric accents).
* **Gamified Visa System:** Every lifestyle choice you make doesn't just add to a score—it unlocks official clearance badges and dynamic visa stamp cards in real time.
* **100% Vanilla Tech Stack:** Built with pure HTML5, CSS3, and modern JavaScript. No heavy frameworks, bloated build tools, or complicated configurations required—just clean, readable web code.
